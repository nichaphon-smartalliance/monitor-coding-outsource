# Project Requirement — ShopX Backend (ตัวอย่าง)

> สเปก "ตั้งต้น" ของโปรเจกต์ ตอนเริ่มทำ — ใช้ให้ AI เข้าใจว่าระบบนี้ควรทำอะไรได้บ้าง
> (ไฟล์นี้แทบไม่เปลี่ยน เปลี่ยนเฉพาะตอนขยายขอบเขตโปรเจกต์)

## ภาพรวม
ระบบหลังบ้านร้านค้า ShopX สำหรับจัดการลูกค้า คำสั่งซื้อ และรายงานยอดขาย

## ขอบเขตงานหลัก
- **โมดูลลูกค้า (customer):** เก็บข้อมูลลูกค้า — ชื่อ เบอร์โทร ที่อยู่
- **โมดูลใบกำกับภาษี (invoice):** ออกใบกำกับ คำนวณ VAT 7%
- **โมดูลรายงาน (report):** สร้างรายงานยอดขาย export เป็น PDF

## เทคโนโลยี
Node.js
